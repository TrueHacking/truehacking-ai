# Prompt 02: desenvolvimento

Crie a UI Streamlit, um servidor HTTP de laboratório com as rotas / e /seguro e um Compose com serviços isolados. Mostre status, cabeçalhos, tempo, título e presença de CSP, Referrer-Policy e X-Content-Type-Options. Não aceite URL arbitrária, não siga redirecionamentos e não execute scanners. Adicione testes simulados e documentação multiplataforma.
