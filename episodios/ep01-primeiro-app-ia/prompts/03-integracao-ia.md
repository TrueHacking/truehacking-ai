# Prompt 03: IA local

Integre a API /api/chat do Ollama para explicar em português os resultados HTTP. Configuração por variáveis de ambiente. Distinga fatos e hipóteses; não invente achados. A IA não pode executar comandos, modificar arquivos nem fazer novas requisições HTTP. Mantenha o aplicativo funcional quando Ollama estiver indisponível.
