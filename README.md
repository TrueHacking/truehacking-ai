## Nosso compromisso

- Linguagem acessível a quem está começando em IA e TI.
- Aplicações e laboratórios em containers Docker, com builds para AMD64 e ARM64.
- Instruções para Windows, Linux e macOS, incluindo limitações de GPU e modelos locais.
- Ambientes próprios e autorizados para todas as demonstrações de segurança.
- Projetos open source, com prompts, código, testes, documentação e desafios da comunidade.

## Como participar

Acompanhe a série no canal [True Hacking](https://www.youtube.com/@TrueHacking), abra issues com sugestões e envie pull requests. Materiais e instruções serão publicados na pasta de cada episódio.

> Atenção: o código é educacional. Não faça testes em sistemas sem autorização explícita.
